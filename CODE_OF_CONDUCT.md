# Código de Conduta

Este projeto segue o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Resumindo: seja respeitoso, aceite críticas construtivas, ajude quem está começando e foque no que é melhor para o projeto e para quem usa o app. Assédio, ofensas e ataques pessoais não são tolerados.

Para relatar um problema de conduta, fale diretamente com o mantenedor, [@paulpessoa](https://github.com/paulpessoa), pelos contatos do perfil no GitHub. Todas as denúncias serão analisadas com sigilo.
